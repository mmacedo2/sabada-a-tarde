# Sábado à Tarde

Quero fazer um redesign COMPLETO do website da Associação de Futebol Popular de Guimarães (AFPG):

https://www.afpguimaraes.com/

O objetivo não é simplesmente mudar cores ou trocar o template. Quero criar uma versão muito mais moderna, profissional, desportiva e visualmente apelativa da AFPG, mantendo a identidade histórica da Associação e, principalmente, mantendo a identidade individual de todos os clubes/equipas.

1. OBJETIVO GERAL

Transformar o atual website da Associação de Futebol Popular de Guimarães num website com aparência de uma organização desportiva moderna e profissional.

O resultado deve transmitir:

Futebol

Competição

Comunidade

Tradição

Guimarães

Modernidade

Credibilidade

Paixão pelo futebol popular

Quero uma estética comparável à de websites modernos de federações, ligas e competições desportivas, mas sem copiar nenhuma identidade existente.

O site atual deve ser utilizado como referência de conteúdo e estrutura, mas NÃO como referência visual.

Website atual:
https://www.afpguimaraes.com/

Analisa o website atual, as páginas existentes, os menus, as competições, os clubes, os símbolos e a informação disponível antes de começares a desenvolver.

2. REGRA MAIS IMPORTANTE: IDENTIDADE DOS CLUBES

Existe uma grande quantidade de clubes/equipas associados à AFPG.

Quero modernizar TODOS os símbolos/logótipos existentes.

MAS:

NÃO quero substituir os símbolos por logos completamente diferentes.

Cada clube deve continuar a ser imediatamente reconhecível.

A modernização deve funcionar como uma evolução da identidade existente.

Para cada símbolo:

Identificar os elementos visuais fundamentais do símbolo atual.

Preservar a identidade histórica.

Preservar as cores principais.

Preservar nomes, iniciais e elementos gráficos importantes.

Simplificar formas demasiado complexas.

Melhorar proporções.

Melhorar tipografia.

Criar formas vetoriais mais limpas.

Melhorar legibilidade em tamanhos pequenos.

Criar uma versão adequada para utilização digital.

Dar um aspeto contemporâneo e profissional.

Pensa no processo como:

"modernização / rebranding evolutivo"

e NÃO como:

"criar um novo logo".

Exemplo conceptual:

Se um clube tem atualmente um escudo antigo com uma bola, iniciais e cores específicas, esses elementos devem continuar presentes, mas podem ser redesenhados de forma mais elegante, geométrica e contemporânea.

NÃO remover elementos históricos só porque parecem antigos.

A história dos clubes é importante.
